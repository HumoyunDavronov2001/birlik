# Security policy

BIRLIK moves model data between devices, so security reports are taken seriously.

**Please do not open a public issue for a vulnerability.** Report it privately through GitHub:
*Security → Report a vulnerability* on this repository. You will get an answer within 7 days.

Useful details: the affected component (`node/`, `engine/`, `protocol/`, `web/`), the version or commit, steps to
reproduce, and the impact you expect.

The project is pre-alpha (stage B0): there is no released version yet, and nothing should be run on untrusted
networks.
